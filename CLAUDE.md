# Ева Нумеролог — как работать с этим репозиторием

Telegram-бот [@nnumerology_bot](https://t.me/nnumerology_bot) плюс Mini App
(веб-кабинет). Русскоязычная нумерология: разборы генерирует ИИ по числам,
посчитанным из даты рождения и имени.

Файл читается автоматически в начале каждой сессии. Держи его в актуальном
состоянии: **устаревший факт здесь хуже, чем отсутствующий** — по нему начинают
искать баг не в том месте.

## Про пользователя

Руслан, solo founder, без бэкграунда в программировании, работает с телефона
(Android). Общение по-русски, неформально, без канцелярита; ценит прямые ответы
и не любит, когда что-то делают, не спросив.

Правки вносим и пушим **сами, прямо в `main`** — оттуда автодеплой на Railway.
Целые файлы в чат вываливать не надо: это осталось с тех пор, когда он копировал
код руками. Достаточно сказать, что изменили и почему.

## Как устроен код

| Файл | За что отвечает |

| `readings.py` | 39 промптов разборов — по одному на разбор |

| `ai.py` | цепочка провайдеров и постобработка ответа модели |

| `keyboards.py` | инлайн-клавиатуры |

| `achievements.py` | значки-достижения, общие для бота и веба |

## Цифры, которые важно не перепутать

- **40** ключей в `TITLES`, из них **39** платных (`PAID_RAZBORY`); 40-й — `free`.
  Промптов ровно 39, по одному на платный разбор.
- Цены: 49⭐ (9 разборов), 79⭐ (15), 99⭐ (10), 149⭐ (5).
- Премиум: 399⭐ или 720₽. Курс пересчёта `STARS_TO_RUB_RATE = 1.8`.
- Реферал: 25% пригласившему, 20⭐ приглашённому сразу. За отзыв — 10⭐.
- Разбор на другую дату — отдельная покупка со скидкой 30%.
- Лимиты в день: повторные генерации 10 (премиум 25), «Спроси Еву» 25,
  «Да/Нет» 3 бесплатно.

## Правила, которые легко нарушить

**ИИ-провайдеры идут в порядке OpenRouter → Cerebras → Groq.** Не наоборот.
Каждому даётся вторая попытка, ответ проверяется на полноту структуры (≥60%
ожидаемых блоков) и на то, что не оборвался на полуслове. Общий бюджет
`ASK_AI_BUDGET = 150с`. Когда у OpenRouter кончаются кредиты — 402, попытка
падает, генерация уходит на бесплатные провайдеры, бот продолжает работать.

**Новый эмодзи-заголовок блока добавляется в `header_emoji.py`, и только туда.**
Список раньше жил в двух копиях и разъехался: блоки с «неизвестным» эмодзи не
считаются блоками — не проходят проверку структуры, не выделяются жирным и
склеиваются с предыдущим текстом в PDF.

**Пол пользователя неизвестен по умолчанию.** Не пиши текстов в женском роде.
Где пол правда нужен — `db.is_male(user)`, а в промптах `_gender_note`.
Заглушки вместо имени перечислены в `numerology.PLACEHOLDER_NAMES`: по ним
нельзя считать числа имени, иначе человек получит числа слова «дорогой».

**Каждое изменение денег — атомарный `UPDATE ... WHERE guard RETURNING`.**
Проверка и списание одним запросом, иначе двойной клик проходит обе проверки.
Где нужен read-modify-write — под `db.user_lock(user_id)`.

**Внешнее действие делается до того, как состояние стало необратимым.**
Отзыв публикуется в канал раньше, чем удаляется из очереди (а при сбое
возвращается назад) — иначе он пропадает совсем.

**У вебхука ЮKassa нет FSM.** Нельзя просить «пришли дату сообщением» —
ждущего состояния некому выставить, и ответ уйдёт в пустоту. Только кнопка
(`startreading_` / `startredate_`).

## Проверки

Статические, без базы и без сети — гоняй перед каждым коммитом:

```
python3 tests/check_static.py
```

Постобработка текста ИИ — нужен только httpx:

```
python3 tests/test_ai_text.py
```

Денежные и миграции, нужен PostgreSQL (как поднять — см. `tests/README.md`):

```
DATABASE_URL=$(sh tests/pg_start.sh) python3 tests/test_money.py
DATABASE_URL=$(sh tests/pg_start.sh) python3 tests/test_migrations.py
```

Сегодняшний опыт: баги почти никогда не в арифметике. Они в том, **чего модели
не дали** (голое число без значения — и она придумывает значение сама), **чего
не узнал конвейер** (эмодзи не в списке — блок не посчитан) и **где слои
противоречат друг другу** (в промпте зашит женский род, а `_gender_note`
говорит про мужчину).

## Деплой

Railway, автоматически из `main`. Сборка по `Dockerfile` (там же системные
библиотеки для WeasyPrint и `TZ=UTC` — расписание считается в UTC).
`amvera.yaml` и `DEPLOY_AMVERA.md` — запасной вариант переезда, Railway их
игнорирует.

Переменные окружения: `BOT_TOKEN`, `DATABASE_URL`, `WEBAPP_URL`,
`OPENROUTER_API_KEY`, `CEREBRAS_API_KEY`, `GROQ_API_KEY`, `YOOKASSA_SHOP_ID`,
`YOOKASSA_SECRET_KEY`. `PORT` по умолчанию 8080.
